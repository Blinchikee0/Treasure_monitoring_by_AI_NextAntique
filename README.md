# NextAntique

Автономная роботизированная система мониторинга, оцифровки и предиктивной защиты объектов культурного наследия с применением алгоритмов машинного обучения.

## Обзор проекта

Проект NextAntique разработан командой CyberCrafters (НИШ ЕМН г. Актобе) и направлен на решение глобальной проблемы ускоренной климатической деградации и утраты археологических памятников. В отличие от традиционных пассивных систем фиксации ущерба, NextAntique реализует концепцию "цифрового бессмертия" (Digital Immortality), совмещая непрерывный IoT-мониторинг, предиктивную аналитику на базе искусственного интеллекта и построение динамических 4D цифровых двойников.

### Ключевые преимущества системы
* Ликвидация «слепых зон» за счет мобильного сканирования и построения непрерывных тепловых карт.
* Предиктивное опережение благодаря анализу скрытых корреляций факторов окружающей среды с точностью предотвращения разрушений до 92.4%.
* Технология Edge Computing, обеспечивающая обработку первичных данных непосредственно на борту робота в условиях отсутствия связи.
* Виртуальное стресс-тестирование в среде 3D Digital Twin для планирования точной реставрации.

## Архитектура комплекса

Система разделена на два взаимосвязанных контура: аппаратный (Hardware) и программный (Software).

### 1. Роботизированное и аппаратное решение
* **Основной робот-реставратор:** Автономный аппарат, осуществляющий сканирование крупных объектов по изменяемым осям с использованием тригонометрических расчетов. Отвечает за сбор изображений, генерацию облака точек, поиск скрытых металлических артефактов методом электромагнитного сканирования и локальное устранение микротрещин.
* **Наземная станция:** Статичный модуль, размещаемый непосредственно в исследуемой зоне. Оснащен комплексом датчиков для непрерывного сбора климатических и геологических параметров.

#### Спецификация компонентов:
* **Основной робот:** ESP32-CAM (OV3660), Esp-32 Wroom, драйвер моторов L298N, мотор-редукторы, Li-ion аккумуляторы, солнечная панель.
* **Наземная станция:** Вычислительный модуль Raspberry Pi, датчики BMP280 (давление/высота воды/атмосферные данные), SW-420 (вибрация), HW-038 (влажность почвы), HW-028 (уровень осадков), DS18B20 (температура воды), Wind valve turbine (скорость ветра), солнечная панель.

### 2. Программное обеспечение и ИИ
* **Интерфейс и веб-приложение:** Реализовано на базе Chromium Embedded Framework с визуализацией данных через дашборд Streamlit.
* **Бэкенд:** Высокопроизводительный API на FastAPI, обеспечивающий обмен данными между серверами, роботами и базой данных.
* **Генерация 3D-моделей:** Облако точек преобразуется в полигональную сетку цифрового двойника с помощью Meshy 3D.
* **Предиктивная модель ИИ (LSTM/GRU):** Рекуррентная нейронная сеть (архитектура GRU с механизмами MultiHeadAttention и слоями LayerNormalization), прогнозирующая риски на основе 4 параметров: влажности, температурных колебаний, сейсмовибрационной нагрузки и уровня воды.
* **Распознавание паттернов:** Дополнительный модуль на базе Kraken OCR CNN для анализа изображений и расшифровки закономерностей мозаичных структур.
